BigWave Radio VERSION - Linux
==============================================================
MIT - https://github.com/postmanpat-303/BigWaveRadio
Created by Derek Heasley. Buy me a coffee: https://buymeacoffee.com/postmanpat

Run:     ./bigwave-radio
Install: ./install.sh          (for your user: ~/.local/bin + applications menu)
Remove:  ./install.sh --uninstall

Needs the usual desktop libraries: ALSA (or PipeWire/PulseAudio's ALSA layer),
OpenSSL 3, OpenGL, and X11 or Wayland.

Your library, ratings, settings and plugins live in ~/.local/share/BigWaveRadio
($XDG_DATA_HOME/BigWaveRadio). There is no tray icon on Linux yet: closing the
window quits. Check for updates is on the About page.
